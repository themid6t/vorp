Users & policy.

        
Approve names, set quotas and manage accounts. Changes reach live tunnels immediately.

      

      
Reservation requests

      
Users without direct reservation ask for names here. A pending request holds the name, so nobody else can take it until you decide.

      


      
Users

      
Values marked default follow the default quotas. Admins are exempt from quotas. "Direct" users get reserved names at once, without a request. You cannot remove your own admin role.

      


      

        
Default quotas

        
For every non-admin user without an override. Lowering the tunnel limit does not close tunnels that are already open.
